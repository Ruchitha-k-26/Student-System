# Student System (Client–Server with WebSockets)

This project demonstrates a *Python-based client-server system* for sending and receiving student records using WebSockets.  
It includes file operations, performance monitoring, and memory usage tracking.


##  Features
- Load student records from a .txt file (students.txt)  
- Sort student records by any attribute (name, age, grade)  
- Send data from client to server via *WebSockets*  
- Save student data to output.csv on server  
- Track performance:
  - File load time
  - Sort time
  - Transmission time
  - Save time
  - Memory usage (both client & server)

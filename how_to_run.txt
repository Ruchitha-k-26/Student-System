  HOW TO RUN STUDENT SYSTEM

1. Install Python 3.10 or later
   Download: https://www.python.org/downloads/

2. Install dependencies
   Open terminal/command prompt in project folder and run:
   pip install -r requirements.txt

3. Start the Server
   Open a terminal in the project folder and run:
   python server.py
   - You should see: [SERVER] Server started at ws://localhost:8765

4. Run the Client
   Open another terminal in the same folder and run:
   python client.py
   - The client will send student data to the server
   - Server will acknowledge and save the data into output.csv

5. Check Results
   - Input file: students.txt
   - Output file: output.csv (generated by server)
   - Performance statistics (load time, sort time, transmit time, memory usage) are printed in both client and server consoles

6. Notes
   - Make sure the server is running before starting the client
   - Works on localhost (both client and server on same machine)
